# Templates dos Books

Esta pasta conterá (Fase 2) os **templates Excel** de cada Book — planilhas
vazias, formatadas, com as colunas corretas, validações de célula e
instruções, para a casa preencher conforme a especificação em
[`../schema/`](../schema/).

Status: **em construção (Fase 2)**.

Templates planejados:

```
B1_processos_template.xlsx
B2_apontamentos_template.xlsx
B4_regulacao_template.xlsx
B5_controles_template.xlsx
B6_riscos_template.xlsx
B7_visoes_template.xlsx
B8_externos_template.xlsx
B9_disciplinas_template.xlsx
B10_indicadores_template.xlsx
```

Cada template terá:
- Cabeçalhos exatos conforme a spec
- Tipos e validações de célula (listas suspensas para enums)
- Uma aba de instruções
- Linhas de exemplo (a serem apagadas pela casa)
